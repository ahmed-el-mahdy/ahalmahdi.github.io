# Personal & Family Command Center

Private-first dashboard architecture.

## Data policy
- No real financial, family, or health records should be committed to this repository while it is public.
- Prototype settings are browser-local only.
- Replace example data with local/private storage before production use.

## Boards
- Master Dashboard
- Financial
- Investments
- Mobility
- Career
- Family Goals
- Health Budget

## Planned architecture
UI and calculations are separated from user data so the repository can remain safe to publish. The dashboard should support monthly snapshots, scenario analysis, and export/import without requiring sensitive data in Git.
